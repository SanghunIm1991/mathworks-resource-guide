# MATLAB/Simulink公式情報のテーマ別リンク集（Claude Codeによる調査・整理）

## 概要・きっかけ

MATLAB/Simulinkによるモデルベース開発（MBD）での利用を想定する。MATLAB/Simulinkは、MathWorksの公式サイト以外に参考になるプログラムや解説があまりない。一方で、公式サイトの中で調べたいページに、検索エンジンから一度でたどり着けないことがある。

そこで、Claude Codeにテーマごとに調べさせ、「概要」と「リンク先」を整理したリンク集を作る。

- **調査対象（情報源）**: MathWorksの公式サイト（ドキュメント、製品ページ、ブログ、ビデオ）、MathWorks主催の講演資料（MATLAB EXPO等）、YouTubeの「MATLAB」チャンネルと「MATLAB Japan」チャンネル
- **当面のテーマ**:
  1. プログラムによるSimulinkモデルのブロックとコンフィギュレーションの変更
  2. 設計情報からのテスト自動生成
  3. プラントモデルをニューラルネットワークに置き換えるサロゲート化

## 評価

- **良い点**
  - 公式の情報は量が多いが散らばっている。テーマ単位で「どの関数・アプリ・例題から読めばよいか」を1枚にまとめると、調べ直しの手間が減る
  - 情報源を公式に限るので、内容の信頼性が高い。第三者のブログを転載しないので、著作権上の心配も少ない（リンクと自分の言葉での要約だけを載せる）
  - テーマを足していけば、参照用の索引として育てられる
- **懸念点**
  - MATLABは年2回（a／b）リリースされ、機能の追加・名前の変更・ページの移動が多い。リンク切れや内容の古さが出るので、確認日とリリース（「R2025b以降」等）を書き添える必要がある
  - 検索結果のURLには国別のサブドメイン（`in.`・`se.`・`kr.`等）が混じる。見る人によって表示言語が変わるので、URLは`www.mathworks.com`か`jp.mathworks.com`に統一したい
  - YouTubeは検索結果だけでは投稿チャンネルを確かめきれないことがある。公式チャンネルの動画かどうかを見分ける必要がある
  - 使う機能の多くは有償のツールボックス（Simulink Test、Simulink Design Verifier、Deep Learning Toolbox等）が前提。必要なツールボックスを、テーマごとに明記する必要がある

## 肉付け（想定する進め方）

- テーマごとに「概要（何ができるか・主な関数やアプリ）」→「リンク（公式ドキュメント／講演資料／動画）」の順に整理する
- 各リンクには一言の説明を付け、必要なツールボックスと対応リリースが分かる場合は書き添える
- 日本語ページがある場合は日本語ページを優先する。MathWorksのドキュメントは、URLの`www.mathworks.com`を`jp.mathworks.com`に替えると日本語版（または日本語サイト上の英語版）が開くことが多い
- テーマが増えたら、テーマごとに別ファイルへ分けることを検討する（リンク集のプロジェクト側で決める）

## 実現性

技術的な難易度は低い。Claude CodeのWeb検索（ドメイン指定で`mathworks.com`・`youtube.com`に絞る）で、公式ページの大半は見つかる。ただし次の点は手作業での確認が残る。

- 講演資料（PDF）は「MATLAB EXPO」と書かれていないもの（ウェビナーの資料等）も多い。「EXPO」で絞らず、テーマのキーワード（日本語・英語）で`mathworks.com`内を検索すると見つかりやすい（2026-10-10、ユーザーの助言による）。それでも新しい年の資料は見つかりにくいので、年ごとの講演一覧ページから探す作業は残る
- YouTubeは動画の中身までは確認できない。タイトルと説明文から判断することになる

## 実現方針（案）

- 調査とリンク集の作成は、別のプロジェクト（リンク集専用のフォルダ・リポジトリ）で行う。本ファイルにはアイデアとしての検討だけを書き、調査結果は載せない
- 着手するときに決めること: リンク集の置き場所と形式（テーマごとに1ファイルのMarkdown等）、テーマを追加するときの調べ方を手順やプロンプトとして固めるか
- URLは推測せず、検索結果で実在を確かめたものだけを載せる
- 情報源の信頼の範囲: MathWorksのドメイン（`mathworks.com`とそのサブドメイン。`jp.mathworks.com`・`blogs.mathworks.com`等）のページは、講演資料・ブログ・ウェビナー資料を含めて信頼して載せる（ユーザーの方針）。MATLAB Answers等のコミュニティの回答は、MathWorksの社員以外の回答もあるので、その旨を書き添える
- 調査した日付をテーマごとに書く
